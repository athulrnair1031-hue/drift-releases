### What's New

One new live theme.

- **MATRIX** — columns of monospace glyphs falling over a near-black field, with
  solid panes so the rain reads in the gaps between cards instead of through the
  text. Twenty themes in total.
- The glyphs are baked once into a single strip bitmap and drawn as tinted
  cells, so it stays cheap: a few hundred texture draws a frame, no per-frame
  allocation. Shaded bands keep the status row and the dock readable.
- MATRIX freezes to one frame in LITE MODE and pauses whenever the drawer,
  search or settings cover home.
- Home chip cycle fixed: GREEN now leads to GLASS instead of skipping to AUTO.
  The order is AUTO → LIGHT → DARK → E-INK → SPACE → GREEN → GLASS → MATRIX →
  the twelve hero themes → AUTO.

### Install

Download `Drift-2.6-release.apk`, open it on the phone, allow install from
unknown apps, then open Drift → **Settings → SET AS DEFAULT LAUNCHER**.

Updating over 2.5 keeps your settings, folders, hidden apps and theme. The APK
is signed with the same release key and shrunk with R8. Android 8.0+.
