### What's New

First signed public build of Drift™ — a gesture-first Android launcher in Kotlin
and Jetpack Compose.

- Seven themes: AUTO, LIGHT, DARK, GREEN, E-INK, SPACE (live starfield) and
  GLASS (liquid backdrop)
- Three drawer layouts: GRID with letter scrubber, PAGES and LIST
- Folders, drawer search, hidden apps, icon packs, unread badges
- Widgets on page 2, torch and system shortcuts
- Double tap home to turn the screen off (optional device admin)
- Edge lighting for notifications and calls (optional overlay)
- Refresh-rate control — SMART, MAX, 60HZ — plus a measured HZ PROBE
- No account, no analytics, no ads, and no INTERNET permission

### Install

Download `Drift-2.4-release.apk`, open it on the phone, allow install from
unknown apps, then open Drift → **Settings → SET AS DEFAULT LAUNCHER**.

The APK is signed with a release key and shrunk with R8. Android 8.0+.
Tested on a Pixel 6 emulator (Android 14, 1080×2400); real-phone high-refresh
behaviour and live-backdrop battery cost are not measured.
