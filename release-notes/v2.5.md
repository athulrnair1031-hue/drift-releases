### What's New

Twelve hero themes and a start-up copy check.

- **Twelve hero themes** — SPIDER-MAN, IRON MAN, BATMAN, SUPERMAN, WOLVERINE,
  DEADPOOL, BLACK PANTHER, SCARLET WITCH, THOR, HULK, CAPTAIN AMERICA and FLASH.
  Nineteen themes in total, all in the home chip cycle and the controls page.
- Each hero theme is a palette plus one **drawn motif** backdrop — gradients,
  arcs and line work at low alpha. No artwork ships, so the APK stays the same
  size. Motifs freeze behind settings, drawer and search, and follow LITE MODE.
- **Modified copies are refused.** Drift now checks its own signing certificate
  at launch. A build repackaged and signed with a different key shows a
  **MODIFIED COPY** notice instead of the launcher, with buttons to open app
  settings or exit, so a bad install can still be removed.
- Settings and About read the version from the build, so they say 2.5.

### Install

Download `Drift-2.5-release.apk`, open it on the phone, allow install from
unknown apps, then open Drift → **Settings → SET AS DEFAULT LAUNCHER**.

Updating over 2.4 keeps your settings, folders and hidden apps. The APK is
signed with the same release key and shrunk with R8. Android 8.0+.

Hero names are used as colour-theme titles only. Drift ships no film stills,
logos or third-party artwork, and is not affiliated with any rights holder.
